# VBV Loading Screen assets

Place the requested client artwork in this folder:

- `LoadingScreen1.png`
- `LoadingScreen2.png`
- `LoadingScreen3.png`
- `Walking.gif`

The VBV build converts `Walking.gif` into PNG animation frames because Minecraft's native texture loader does not animate GIF resources directly.

The three loading images are randomly selected each time a multiplayer connection loading screen is created.
