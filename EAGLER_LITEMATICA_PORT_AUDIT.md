# Litematica / MaLiLib Eaglercraft port audit

Generated by workflow 04 against the pinned Eaglercraft 26.2 u2 workspace.

## Compatibility status

The upstream projects target Fabric/Minecraft 1.21.1. Their JARs are not Eaglercraft browser mods and are not injected into the HTML client. This repository now contains a native Eagler-compatible first-stage port: it imports compressed .litematic files through Eagler's browser file chooser and displays schematic regions, dimensions, palette sizes, and block counts. The upstream Fabric runtime and mixins are not used.
